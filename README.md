# The Agent-Augmented Data Scientist

Companion materials for *The Agent-Augmented Data Scientist*, published by Packt: reusable skills, analytical playbook templates, and worked examples for Cascade Goods.

## Getting started

- [Chapter 1](chapters/chapter_01/README.md) — Find an opportunity for agent augmentation.
- [Chapter 2](chapters/chapter_02/README.md) — Build your team's shared analytical foundation.

Materials for Chapters 3–12 will be added as they are ready.

## Cascade Goods

[Cascade Goods](cascade_goods/) is the fictional retail company introduced in Chapter 2 and used throughout the book. This folder contains its shared context, datasets, and analytical resources for the chapter examples and playbooks.
