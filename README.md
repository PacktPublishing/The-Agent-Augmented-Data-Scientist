# The Agent-Augmented Data Scientist

Companion materials for *The Agent-Augmented Data Scientist*, published by Packt: reusable skills, analytical playbook templates, and worked examples for Cascade Goods.

## Getting started

- [Chapter 1](chapters/chapter_01/README.md) — Find an opportunity for agent augmentation.
- [Chapter 2](chapters/chapter_02/README.md) — Build your team's shared analytical foundation.

## Cascade Goods worked example

The [Cascade Goods folder](cascade_goods/) contains business and team context, analytical standards, a metric registry, an analytical reviewer definition, datasets, SQL, a Python metric runner, and calculation tests. Start with the [data README](cascade_goods/data/README.md) for the dataset's conventions and table relationships.

Use these materials as examples when developing your own team's foundation. Review the definitions, assumptions, and standards for your setting.

Chapters 3–12 currently contain placeholders. Materials will be added as they are ready.
